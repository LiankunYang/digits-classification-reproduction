# 从哪里开始看这个项目

我先把注意力放在数据怎么流动上，再逐步补模型原理。第一次阅读不要求推导 SVM 公式，但应能解释下面这些变量。

## 1. 输入到底是什么

| 变量 | 形状 / 含义 |
|---|---|
| `digits.images` | `(1797, 8, 8)`：1797 张图片，每张 8 行、8 列 |
| `X` | `(1797, 64)`：每行一张图片，每列一个像素特征 |
| `y` | `(1797,)`：每张图片对应的数字标签 |
| `train`、`test` | 数据的编号数组，分别有 1347、450 个编号 |
| `X[train]` | 按训练编号取出的图片特征 |
| `y[test]` | 测试图片的正确答案，用于评分 |

`reshape(..., -1)` 把每张二维图片排成一行；`-1` 让 NumPy 推算列数。像素数值表示灰度，不是标签。可在 Notebook 里直接打印第一张图的矩阵和标签对照。

## 2. fit 和 predict

```python
model.fit(X[train], y[train])
prediction = model.predict(X[test])
```

`fit` 根据训练图片和对应答案准备模型。`predict` 只接收测试图片，给出预测数字。最后比较预测与 `y[test]`，计算正确率。测试答案不能提前用来训练或挑参数。

## 3. 两个模型先怎么理解

- KNN：寻找相近的训练样本，用邻居的类别投票。`k=5` 表示参考五个邻居；k 是我需要预设或验证选择的参数。
- SVM：从训练样本学习类别之间的区分方式。本实验使用 RBF 核、`C=1`、`gamma="scale"`，这些参数固定，不做搜索。

这是帮助阅读代码的直观解释，后续仍需要结合课程学习距离、决策边界和核函数。

## 4. 为什么要 Pipeline

标准化根据训练数据每个特征的均值和标准差进行变换。先划分数据，再训练标准化器；测试数据沿用训练部分计算的变换规则。交叉验证中的每一折也要遵循同一原则。

代码把 `StandardScaler` 与模型装在 Pipeline 里。这样训练某一折时，标准化器只会看到该折的训练部分。方法依据：[scikit-learn 数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)。

## 5. 交叉验证在做什么

本项目将训练集分成五折，每次用其中四折训练、一折验证，轮换五次。对每个候选 k 都计算五个验证准确率，再看平均值。`knn_cv.csv` 保存每折成绩；图里的误差线是折间标准差，不是置信区间。

选完 k，重新用全部 1347 张训练图拟合 KNN，最后在 450 张测试图上评分。训练集的 CV 平均分与测试分来自不同数据，不能混成同一个结果。

## 6. 如何读输出

| 输出 | 我用它回答的问题 |
|---|---|
| accuracy | 全部测试图片中，预测正确的比例是多少？ |
| precision | 被模型说成某个数字的图片中，有多少真是这个数字？ |
| recall | 真属于某个数字的图片中，有多少被找对？ |
| F1 | precision 和 recall 的调和平均数是多少？ |
| support | 测试集中这个类别有多少张？ |
| 混淆矩阵 | 哪些真实类别被预测成了哪些类别？行是真实，列是预测 |
| errors.csv | 每个错误在原始数据中的编号、真实标签、预测标签是什么？ |

例如 SVM 的 `441/450=98%`，仍有 9 张错误。真实标签 8、预测 1 的错误会记在混淆矩阵的第 8 行、第 1 列（按数字标签读），而不是对角线上。

## 7. 报错时按这个顺序查

1. `No module named sklearn`：核查当前 Python 是否是安装依赖的 `.venv`；安装包名是 `scikit-learn`。
2. `No module named digits_workflow`：Notebook 应和 `digits_workflow.py` 放在同一仓库目录，先运行第一个代码单元。
3. `NameError`：重启内核后从第一格开始运行，不要跳过定义变量的格子。
4. Notebook 不能运行：安装 `requirements-notebook.txt`，在右上角选 `.venv` 内核。
